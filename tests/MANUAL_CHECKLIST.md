# 浏览器端手工验收清单

自动化测试（`node --test tests/*.test.mjs`）只覆盖核心数据逻辑和静态检查。以下项目需要在真实浏览器里逐项确认；建议同时在一个桌面浏览器和一台手机上走一遍，并在“结果”列记录实际情况（不要预填）。

开始前：打开开发者工具 → Application/存储 → 删除 `mogrid.scene.v1` 与 `mogrid.view.v1`，然后双击打开 `index.html`。

| # | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 1 | 首次打开 | 看到 4 个节点“手机 / 飞书 / Agent / 云电脑”及 4 条带文字的箭头，画面自动居中；顶栏有“仅存本机 · 不联网” | |
| 2 | 开发者工具 Network 面板刷新页面 | 除 `index.html` 本身外没有任何请求；Console 无报错 | |
| 3 | 按 `N` | 视口中心出现“新节点”，右侧标题框已聚焦并选中文字 | |
| 4 | 输入中文标题和多行长说明（>200 字） | 画布实时更新；节点变高；说明超过 5 行显示“…”；悬停显示全文 | |
| 5 | 拖动节点 | 节点跟随；相连箭头端点始终贴在矩形边框上 | |
| 6 | 单击节点（不移动） | 只选中，节点位置不变（检查 JSON 坐标或撤销按钮状态未变化） | |
| 7 | 点“飞书”，Shift+点“云电脑”，按 `L` | 出现 飞书 → 云电脑 箭头；节点上曾显示“起/终” | |
| 8 | 按 `L` 进入连线模式，拖动节点 | 节点不移动；依次点击两个节点后生成连线 | |
| 9 | 对同一对节点重复连线、或连到自身 | 红色提示，不生成连线 | |
| 10 | 选中连线 → Delete；选中节点 → Delete | 连线/节点被删除，节点相关连线一起删除 | |
| 11 | 连续做 12 次修改后按 `Ctrl/⌘+Z` 12 次，再 `Ctrl/⌘+Shift+Z` 12 次 | 能逐步撤销与重做，最终回到修改后的状态 | |
| 12 | 在标题输入框内按 `Ctrl/⌘+Z` | 只撤销输入框文字，不撤销画布 | |
| 13 | 刷新页面 | 内容与视图位置还原 | |
| 14 | 点“清空” → 取消 | 画布不变 | |
| 15 | 点“清空” → 确认清空 → 刷新 | 画布为空；（刷新前）可用撤销找回 | |
| 16 | 导出 PNG，用看图软件打开 | 白底、文字清晰可读（中文无乱码）、箭头方向正确、连线文字可见 | |
| 17 | 导出 JSON → 清空 → 导入该 JSON | 布局完整恢复 | |
| 18 | 导入一个非 JSON 文件 / 缺少 format 的 JSON | 显示“导入失败：…”，画布不变 | |
| 19 | 导入标题为 `<img src=x onerror=alert(1)>` 的 JSON | 节点上原样显示这串文字，不弹窗 | |
| 20 | 手机打开（或开发者工具 375px 宽） | 顶栏不溢出；属性面板为底部抽屉；单指拖动画布/节点、双指缩放可用 | |
| 21 | 无痕/隐私窗口打开 | 能使用；若无法写入存储，顶栏显示红色警告 | |
