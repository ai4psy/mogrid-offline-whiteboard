# 墨格 MoGrid · 轻量架构白板（离线单文件）

一个**双击即可打开**的架构图小白板：矩形节点 + 带箭头的连线，专门用来快速画“AI 应用数据流”这类示意图。整个应用就是一个 `index.html`，CSS 和 JS 都内联在里面：没有依赖、不用构建、不连网络。

想让 Claude Code 从空目录生成类似工具，可参考 [PROMPT.md](PROMPT.md)；生成后仍需自己验收。

> 灵感来源：[Excalidraw](https://github.com/excalidraw/excalidraw)（开源手绘风白板）。
> **本项目为独立实现，未复制原仓库的代码、品牌、图标、图片或文案**，只借鉴了“无限画布 + 节点 + 箭头 + 本地保存”这类通用交互思路。它**不是** Excalidraw 的复刻，功能少得多（见“功能边界”）。

---

## 1. 快速开始

1. 下载或复制 `index.html` 到任意文件夹。
2. 用桌面浏览器（Chrome / Edge / Firefox / Safari 的较新版本）**双击打开**即可。
3. 首次打开会载入示例场景：**手机 → 飞书 → Agent → 云电脑**（另有一条 Agent → 飞书 的“回复结果”回传线），可以直接截图使用。

不需要 `npm install`，不需要本地服务器。

## 2. 功能

| 功能 | 怎么用 |
| --- | --- |
| 新增节点 | 左侧工具条“＋”、按 `N`、或双击画布空白处 |
| 编辑标题 / 说明 | 选中节点后在右侧“属性面板”编辑；双击节点会直接聚焦标题框。说明支持换行 |
| 改颜色 / 宽度 | 属性面板中的 6 种配色与宽度滑块（140–360 px）|
| 拖动节点 | 按住节点拖动；多选后可一起拖动 |
| 多选 | `Shift`（或 `Ctrl` / `⌘`）+ 点击；`Ctrl/⌘ + A` 全选 |
| 添加连线 | **方式一**：先点起点、再 `Shift`+点终点，按 `L` 或点面板里的“添加连线”（节点上会显示“起 / 终”标记，可点“交换方向”）。**方式二**：按 `L` 进入连线模式，依次点击起点和终点 |
| 连线文字 / 反转 | 点击连线，在右侧填写文字（如“调用”“推送”）或“反转方向” |
| 删除 | 选中节点或连线后按 `Delete` / `Backspace`，或点删除按钮；删除节点会同时删除与它相连的线 |
| 撤销 / 重做 | `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`（也支持 `Ctrl + Y`），顶栏也有按钮。最多保留 100 步 |
| 平移 / 缩放 | 拖动空白处或滚轮平移；`Ctrl/⌘ + 滚轮`、触控板双指捏合、手机双指缩放；右下角按钮可放大 / 缩小 / 适应画布（`F`）|
| 导出 PNG | 顶栏“导出 PNG”，按 2 倍分辨率生成白底图片，含节点文字、连线、箭头和连线文字 |
| 导出 JSON | 顶栏“导出 JSON”，保存完整布局 |
| 导入 JSON | 顶栏“导入 JSON”选择文件，或把 `.json` 文件直接拖到画布上 |
| 示例场景 | 顶栏“示例”（需确认，可撤销）|
| 清空画布 | 顶栏“清空” → 弹窗中再点“确认清空”（二次确认，可撤销）|

### 防误触设计

- 指针移动超过 4 像素才算“拖动”，否则视为“点击”，所以点选不会让节点轻微位移。
- 连线模式下节点**不能被拖动**，只响应点击；拖动画布空白处也不会误建连线。
- 连线有 16 px 宽的透明点击区域，细线也容易选中。
- 在输入框里按 `Ctrl/⌘ + Z` 是浏览器原生的文字撤销，不会误撤销画布；按 `Delete` / `N` / `L` 也不会触发画布操作。

### 中文与长文本排版

- 中文按字断行，英文按单词断行，超长英文串（如 URL）强制断开；`，。、；：！？）」` 等标点不会出现在行首。
- 节点高度随文字自动增长；标题最多 2 行、说明最多 5 行，超出用“…”省略。完整内容仍保存在数据里，鼠标悬停节点可看到全文。
- 标题最长 60 字、说明 400 字、连线文字 30 字（按字符计，emoji 不会被切坏）。

## 4. 数据存储位置

- **只存在当前浏览器的 `localStorage` 里**，不会上传到任何地方：
  - `mogrid.scene.v1`：画布内容（与导出的 JSON 格式相同）
  - `mogrid.view.v1`：画布平移 / 缩放位置
  - `mogrid.scene.v1.corrupt`：只有本地数据损坏、无法读取时才会出现，用于保留原数据
- 每次修改后约 0.3 秒自动保存，顶栏会显示“已自动保存到本机浏览器 · 时间”。
- 刷新页面后自动恢复。**撤销历史只在内存中，刷新后不保留。**
- 换浏览器、换电脑、使用隐私/无痕窗口、清除浏览器站点数据，都会看不到之前的内容。**重要的图请“导出 JSON”备份。**
- 通过 `file://` 打开时，不同浏览器对本地文件的 localStorage 处理不同（例如 Chrome 让所有本地文件共享同一个存储空间；部分浏览器可能在关闭后不保留）。如果顶栏显示“无法写入本地存储”，请以导出 JSON 的方式保存。

## 5. 导出 / 导入步骤

**导出 PNG**：点顶栏“导出 PNG” → 浏览器下载 `mogrid-年月日-时分.png`。图片按内容范围自动裁切，四周留白，2 倍清晰度（超大图会自动降低倍率，单边上限 8000 像素）。

**导出 JSON**：点“导出 JSON” → 下载 `mogrid-年月日-时分.json`。

**导入 JSON**：点“导入 JSON”选择文件（或把文件拖到画布）→ 校验通过后**替换**当前画布，可用撤销回到导入前。

JSON 格式示例：

```json
{
  "format": "mogrid-scene",
  "version": 1,
  "app": "MoGrid",
  "nodes": [
    { "id": "n_phone", "x": 0, "y": 0, "w": 200, "title": "手机", "desc": "用户发出任务", "color": "slate" }
  ],
  "edges": [
    { "id": "e_1", "from": "n_phone", "to": "n_feishu", "label": "发送指令" }
  ]
}
```

### 导入时的安全校验

- 文件上限 2 MB；必须是 JSON 对象，且 `format` 为 `mogrid-scene`、`version` 为 1。
- 节点最多 300 个、连线最多 1000 条；`id` 只允许字母、数字、`_`、`-`（最长 64）且不能重复；坐标必须是有限数字（超出 ±100000 会收拢）。
- 连线必须引用存在的节点；自连和重复连线会被忽略并提示。
- **只读取白名单字段**，其余字段（如 `onclick`、`html`、`__proto__`）全部丢弃；颜色只接受内置的 6 个名字。
- 文本会去掉控制字符、零宽字符和双向覆盖字符，并按长度上限截断。
- 所有文字一律用 `textContent` / Canvas `fillText` 当作**纯文本**显示，**不会被当作 HTML 或脚本执行**；代码中不使用 `innerHTML`、`eval`、`new Function`。
- 校验失败会提示具体原因（如“第 3 个节点的坐标 x/y 必须是有限数字”），当前画布保持不变。

## 6. 隐私与离线

- 页面带有内容安全策略（CSP）：`default-src 'none'; connect-src 'none'` 等，浏览器层面禁止加载任何外部脚本、样式、字体、图片或发起网络请求。
- 没有统计、埋点、追踪代码，没有 CDN，没有外部字体（使用系统中文字体：苹方、微软雅黑、思源黑体等）。
- 示例场景只包含通用名词，不包含任何真实用户信息、令牌、私有地址或账号。

## 7. 功能边界（有意不做 / 尚未做）

- 只有**矩形节点**和**直线箭头**，没有手绘风格、自由画笔、圆形/菱形、曲线或折线连线、文字框、图片。
- 连线是“中心对中心”的直线，端点自动落在矩形边框上；节点重叠时该连线暂时不显示。没有自动布局、对齐吸附、框选（请用 Shift+点击 或 Ctrl/⌘+A 多选）。
- 没有复制粘贴、分组、图层、多画布、协作、云同步、分享链接。
- 撤销历史不跨刷新保存；多个标签页同时打开会互相覆盖保存（以最后保存的为准）。
- 导出仅 PNG 与 JSON（没有 SVG/PDF）；JSON 格式与 Excalidraw 的 `.excalidraw` 文件**不兼容**。
- 手机上以“查看 + 轻量编辑”为主：属性面板变为底部抽屉（点击标题栏展开），双指缩放；手机上双击/双击缩放行为因浏览器而异。
- 未针对屏幕阅读器做完整的画布无障碍支持（按钮有 aria 标签）。

## 8. 代码结构（适合阅读和修改）

`index.html` 内分三块：

1. `<style>`：全部样式，顶部 `:root` 里是颜色变量；`@media (max-width: 760px)` 是手机布局。
2. `<script id="mogrid-core">`：**纯逻辑、无 DOM**——场景数据结构、增删节点/连线、JSON 序列化与校验、中文断行排版、连线几何、撤销/重做栈。导出为 `window.MoGridCore`，测试直接在 Node 中加载这一段。
3. `<script id="mogrid-app">`：界面——SVG 渲染、指针手势（拖动/平移/双指缩放/连线）、键盘快捷键、属性面板、localStorage 自动保存、导入导出、弹窗与提示。

想加一种节点颜色：改 `PALETTE`；想改节点字号或最大行数：改 `STYLE`；想改上限：改 `LIMITS`。屏幕上的 SVG 和导出的 PNG 共用同一份 `layoutNode` 排版结果，所以改一处两边一致。

`window.__mogrid` 暴露了只读调试入口（状态、撤销、导入、生成 PNG 画布），便于在浏览器控制台里自测，不影响功能。

## 9. 测试

测试只用 Node 内置的 `node:test`，**无需安装任何依赖、无需网络**（需要 Node.js 18 及以上；编写时环境为 v20.19.2）。在本 README 所在目录执行：

```bash
node --test tests/*.test.mjs
```

或等价的：

```bash
npm test
```

（`package.json` 只用于提供这个命令，没有任何依赖。）

- `tests/core.test.mjs`：从 `index.html` 中提取 `<script id="mogrid-core">`，在 Node 的 `vm` 沙箱（没有 `window`/`document`/`fetch`）里运行，测试：默认示例场景、增删节点与连线、撤销/重做 ≥10 步与上限、JSON 往返、各类非法 JSON 的拒绝、脚本/HTML 注入内容只作为纯文本、控制字符清洗、按字符截断、中文/英文断行与避头标点、省略号、节点自适应高度、连线端点几何与双向错开、视图适配。
- `tests/static.test.mjs`：静态检查 `index.html`：没有外部资源和 URL、没有 `fetch`/`XMLHttpRequest`/`WebSocket`/`sendBeacon`、没有追踪代码、CSP 禁网、不使用 `innerHTML`/`eval`、核心逻辑不依赖 DOM、产品名与声明文案、必要的功能入口都存在、文件体积。
- `tests/MANUAL_CHECKLIST.md`：浏览器端手工验收清单。
